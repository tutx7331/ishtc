    這工具在算什麼

    • MFE（最大有利波動）：你第一次買進之後，這隻幣曾經漲到的最高價，除以你的平均買入成本。這是「你最多能吃到幾 %」的上限。
    • 神之手價值：假設你買進的每一顆都精準賣在歷史最高點，總共會拿到多少錢。
    • 賣飛金額：神之手價值 減掉 你實際賣掉拿到的錢 加上 現在還抱著的市值。這就是你錯過的數字。
    • 出場效率：實際 ÷ 神之手。100% 代表你是神，5% 代表你跟大家一樣。

    全程在你的瀏覽器裡跑，地址與 API key 不會送到任何第三方伺服器，只會直接打 Helius / DexScreener / GeckoTerminal。
