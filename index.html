進階設定

金狗品味

真金狗要漲幅與市值同時過關。分母是你買過的每一隻幣。

漲幅命中率

你買進之後，該幣曾經漲到你成本的幾倍。只看最高點，不管你有沒有賣，也不看市值。

賣飛排行榜

如果每一隻都精準賣在最高點，跟你實際拿到的錢差多少。 點欄位標題可以排序，再點一次換升冪降冪。
賣飛＝賣掉之後它還在漲；雲霄飛車＝沒賣、漲上去又跌回來。兩者相加就是錯過總額。
全損＝現價不到你成本的 5%；已死＝這隻幣流動性見底或從高點跌掉 99%。

數據怎麼算的 / 哪裡會不準

    這工具在算什麼

    • MFE（最大有利波動）：你第一次買進之後，這隻幣曾經漲到的最高價，除以你的平均買入成本。這是「你最多能吃到幾 %」的上限。
    • 神之手價值：假設你買進的每一顆都精準賣在歷史最高點，總共會拿到多少錢。
    • 錯過總額：神之手價值 減掉 實際拿到。可以完整拆成兩種痛 —— 賣飛（賣掉之後它還在漲）與 雲霄飛車（沒賣，漲上去又跌回來）。
    • 神化率：實際 ÷ 神之手。100% 代表你是神，5% 代表你跟大家一樣。
    • 大金狗：MFE ≥ 100x 且 該幣最高市值 ≥ $10M。小金狗：MFE ≥ 10x 且 最高市值 ≥ $1M。

    全程在你的瀏覽器裡跑，地址與 API key 不會送到任何第三方伺服器，只會直接打 Helius / DexScreener / GeckoTerminal / Birdeye。分享卡的背景圖與 logo 也只在本機處理，不會上傳。

    資料來源：Helius（交易紀錄）、DexScreener（池子與現價）、Solana Tracker／Birdeye／GeckoTerminal（買入後最高價）。
    這不是投資建議，只是一份帳單。
