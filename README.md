# ISHTC — I Should Hold The Coin

**你 2026 賣飛了多少錢？** / *How much did you paper in 2026?*

輸入一個或多個 Solana 地址，算出你買過的每一隻 memecoin **買進之後最多漲到幾倍**，
以及那句所有人都不敢問的話：**如果我都不賣，我現在會有多少錢？**

免註冊、免 API key，貼上地址就查。中英雙語。

---

## 它算什麼

| 指標 | 定義 |
|---|---|
| **最高倍數** | 你第一次買進之後，該幣曾到過的最高價 ÷ 你的平均買入成本。 |
| **神之手總值** | 每一隻都精準賣在最高點，總共會拿到多少錢。 |
| **錯過總額** | 神之手 − 實際拿到 ＝ 賣飛（賣了它還在漲）＋ 雲霄飛車（沒賣又跌回來）。 |
| **神化率** | 實際 ÷ 神之手。100% 是神，5% 是正常人。 |
| **大金狗捕獲率** | 最高倍數 ≥ 100x **且**最高市值 ≥ $10M 的比例。 |
| **小金狗捕獲率** | ≥ 10x **且** ≥ $1M 的比例。 |
| **漲幅命中率** | 曾漲到 5x / 10x / 50x / 100x 的比例（不看市值）。 |

**支援多地址**：錢包之間互轉自動抵銷，不會被誤算成賣出。

## 玩法

- 查詢後進入**像素操盤室**：結果顯示在牆上四台螢幕（總結／命中率／排行榜／分享），
  每一隻幣是一條狗從螢幕噴出來——金色是金狗、戴皇冠的是大金狗，
  滑過看幣名、抓起來丟會撞牆翻肚。全場還藏了一隻**失意貓**（買了就忘，拿到十萬倍）。
- **分享卡**：票券式戰績卡（含橡皮章：紙手認證／金狗獵人／鑽石手），一鍵下載。
- **全站排行榜**：金額榜、痛苦指數榜（錯過 ÷ √成本，小額大賣飛才排得上）、金狗榜。
- CSV 匯出、各地址分開比較、可排序分頁的賣飛排行榜。

## 怎麼用

### 線上版

打開網站 → 貼地址 → 查詢。本站代付查詢額度；共用額度冷卻時可自填免費 API key 繼續用。

### 自己架（GitHub Pages 即可）

前端是純靜態網頁（`index.html` + `style.css` + `app.js` + `dogs.js` + `i18n.js`），
fork 之後開 GitHub Pages 就能跑——訪客自備 API key 模式開箱即用。

要讓訪客**免 key** 查詢，需要部署 [worker/](worker/) 的 Cloudflare Worker 代理
（免費方案就夠），詳見 [worker/README.md](worker/README.md)。代理同時提供：

- **幣價資料庫**：任何人查過的幣存進 D1，之後同一隻幣不再重複燒 API 額度
- KV 快取、每月額度守門（超量自動冷卻）、每 IP 限流
- 查詢記錄與全站排行榜（`/leaderboard`）

### 自備 API key（進階）

| 來源 | 用途 | 申請 |
|---|---|---|
| Helius | 交易紀錄（覆蓋最完整） | [dashboard.helius.dev](https://dashboard.helius.dev) 免費方案 |
| Solana Tracker | 區間最高價（最快最準） | [solanatracker.io/data-api](https://www.solanatracker.io/data-api) 免費方案 |
| Birdeye | 最高價備援（選填） | [bds.birdeye.so](https://bds.birdeye.so) |

沒有 key 的部分自動退回免金鑰的 DexScreener / GeckoTerminal。
SOL 歷史匯率走 Binance → Coinbase → GeckoTerminal。

## 安全與隱私

- **這個 repo 裡沒有任何金鑰。** 代理的 key 存在 Cloudflare Worker secrets
  （`wrangler secret put`），不進版本控制。
- 自備 key 只存在**你自己瀏覽器**的 localStorage，全程不離開本機。
- 用本站額度查詢時，查詢地址與統計結果會記錄於後端（排行榜用）；
  自備 key 模式全程在瀏覽器執行，不經過任何伺服器。
- 分享卡的背景圖與 logo 僅在本機處理，不上傳。
